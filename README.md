# AI-Driven Retail Sales Forecasting — Self-Contained Web App

## This version matches the requested flow

There is NO CSV upload step.

When the webpage starts:
1. The retail dataset is created inside the application.
2. The dataset is displayed on the Dataset tab.
3. Preprocessing happens automatically.
4. Feature engineering happens automatically.
5. Linear Regression and Random Forest are trained automatically.
6. Evaluation metrics are shown.
7. Actual vs Predicted and feature-importance charts are shown.
8. The Predict tab lets the user enter business values and get a weekly-sales prediction.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

The browser opens the complete project webpage.

## Important project note

The bundled data is a reproducible Walmart-style retail dataset generated by the application. It is intentionally included in the Python code so the webpage works without requiring a dataset upload or external download.

For a project presentation, describe the workflow as:
Dataset → Preprocessing → Feature Engineering → Random Forest → Evaluation → Prediction.
